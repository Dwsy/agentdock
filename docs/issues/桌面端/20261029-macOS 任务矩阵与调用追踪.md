# Issue: macOS 任务矩阵与调用追踪（Traces）

## Goal

把 GAPP「AgentDock 任务矩阵」的阅读能力移植进 macOS 控制面板：任务列表支持状态筛选、关键字搜索、按项目折叠分组与详情下钻；同时提供可开启的工具调用追踪（入参/出参/来源/耗时），支持搜索与可配置持久化。

## 背景/问题

- 任务状态只存在于 `~/.agentdock/tasks/*.json`，GAPP 能读，原生控制面板不能；用户要开两个窗口才能看同一批任务。
- `Recorder` 刻意只保留元数据（无 Payload），排障时看不到「这次调用到底传了什么、返回了什么」。
- 需求要求 trace 可持久化且保留期可配，不能把大文件或凭据整份写盘。

## 验收标准 (Acceptance Criteria)

- [ ] WHEN 进入 Tasks 页面，系统 SHALL 显示全部任务，并按项目分组、默认折叠
- [ ] WHEN 输入关键字或选择状态，列表 SHALL 即时过滤；命中时分组自动展开
- [ ] WHEN 选中任务，右侧 SHALL 展示 goal、conditions、steps、events、blocker、summary、final review
- [ ] WHEN `AGENTDOCK_TRACE_MODE=off`（默认），Traces 页面 SHALL 明确提示未开启，且 Runtime 不产生序列化开销
- [ ] WHEN `memory`，记录 SHALL 只存在环形内存索引，可按关键字/工具/状态搜索
- [ ] WHEN `disk`，记录 SHALL 批量追加 `<home>/traces/YYYY-MM-DD.jsonl`，重启后可搜索，过期文件按保留天数清理
- [ ] 每条 trace SHALL 每侧最多保留 8 KiB 预览并脱敏 `token/password/secret/api_key/authorization`
- [ ] WHERE Windows / Linux 桌面端，系统 SHALL 无行为变化

## 关键决策

| 决策 | 理由 |
|------|------|
| trace 与 Analytics 分离 | Recorder 的「无 Payload」是安全契约，不能为排障把它改成携带正文 |
| 默认 off | 采集入参出参是隐私敏感操作，必须显式开启 |
| 预览 8 KiB + 脱敏 | 避免大文件/图片 base64 写爆磁盘；JSON 键值走独立脱敏规则 |
| 磁盘按天 JSONL | 追加写、可读、清理只需删文件；无需数据库 |
| 启动回放保留窗口 | 重启后搜索仍覆盖磁盘证据；ID 从最大记录续号 |
| macOS 侧用 List + Section | 原生分组/折叠/选中语义，避免自绘列表 |
