# 降低追踪文本搜索延迟

状态：✅ 已验证

[关联 Issue](../../issues/跨平台UI/20261124-降低追踪文本搜索延迟.md)

## 变更

- 调用追踪识别没有大写字母的 ASCII 正文时，每次检查 8 字节，再用标准库做子串匹配。混合大小写 ASCII 沿用逐字节折叠，非 ASCII 沿用 `strings.ToLower`。
- 回归测试覆盖大小写、标点、Unicode 映射、不合法 UTF-8 以及每个字节在分块中的位置。

## 验证

修改前的对照运行同样复现 `TestTraceProjectRootFindsMarkers` 的本机临时目录问题。测试的向上查找碰到 home 的项目标记。复跑用 `env -u GOTMPDIR TMPDIR="$(getconf DARWIN_USER_TEMP_DIR)"` 给测试进程指定 macOS 临时目录。

- 隔离工作树的 `make check` 通过，覆盖全量 Go 测试、脚本治理、`go vet` 和 Core 构建。
- 当前工作树的 `go test -race ./internal/observability ./internal/app ./internal/httpx -count=1`、对应 `go vet` 和补丁格式检查通过。

## 回滚

撤回 `internal/observability/trace.go` 中本轮的 `containsFold`、ASCII 分块检测及对应导入，移除 `internal/observability/trace_search_test.go`。现有追踪记录可以继续使用。
