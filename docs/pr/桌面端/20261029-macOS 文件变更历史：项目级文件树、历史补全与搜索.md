# fix(desktop): macOS 文件变更历史：项目级文件树、历史补全与搜索

## 背景与目的 (Why)

文件编辑/写入/移动历史大面积缺失：patch 类变更（结构化 envelope 与 unified diff 两种形态）因 `affected_files` 只按 `[]string` 解析而完全不进历史；move 不记录目标；dry_run 假变更混入；多文件 patch 的调用级 +/- 总数冒充单文件统计。文件树把整棵绝对路径摊开，单子链目录要逐层点开，无项目概念，搜索只认路径。

## 变更内容概述 (What)

- **历史补全（Go）**：`traceFileChanges` 归一三种 `affected_files` 形态；过滤 `dry_run`/`changed=false`/失败调用；记录 `move_to`；动词归一 `create/edit/delete/move`；多文件 patch 按 diff 分节统计 per-file +/-（截断为下界，路径按精确/后缀对齐）。
- **项目根（Go）**：路径向上探测 `.git`/`go.mod`/`package.json` 等标记写入 `project_root`，供分组。
- **项目级文件树（Swift）**：按 `project_root` 分组为项目行；单子链压缩成 `src/main/java` 一行；扁平行 + 缩进 + 手动展开集；搜索自动展开全部命中分支。
- **历史时间线（Swift）**：横向 chip 换成纵向时间线（动作徽章、时间、+/-、move `→ 目标`、截断标记），选中看 diff，独立于工具调用记录。
- **搜索（Swift + Go）**：覆盖路径、动作、diff 内容、移动目标；服务端 `file-changes?q=` 同步放宽匹配面。
