# Issue: macOS 托盘增强：阈值告警徽标与代码变动

## Goal

托盘（菜单栏）能看到阈值告警与代码行数变动：面板顶部列活跃告警，菜单栏图标带告警数徽标。

## 背景/问题

后端已有 `/internal/runtime/alerts`（错误率、trace 磁盘、任务阻塞三条规则，含去重与恢复计数），但 macOS 端完全没接：`events-and-alerts` issue 的"托盘/菜单栏显示未读数或状态点"一条至今未做。托盘面板只有服务状态、远程连接、任务与最近调用，用户得自己打开控制面板才发现错误率飙了。

代码行数变动同理：分析页已有增删行数，托盘是"一眼看全局"的入口，却看不到代码改了多少。

## 验收标准 (Acceptance Criteria)

- [x] WHEN 有活跃告警，托盘面板 SHALL 在顶部列出告警（severity 着色，标题按种类本地化）
- [x] WHEN 有活跃告警，菜单栏图标 SHALL 显示告警数量徽标
- [x] WHEN 无告警，菜单栏徽标 SHALL 清空
- [x] WHEN 点击告警，控制面板 SHALL 打开对应页面（错误率→调用分析、磁盘→调用追踪、任务→任务）
- [x] WHEN 窗口内有代码变动，托盘状态卡 SHALL 展示增删行数
- [x] WHEN Core 未运行，告警请求 SHALL 静默失败，不影响托盘其他内容
- [x] WHERE Windows / Linux 桌面端，系统 SHALL 无行为变化

## 关键决策

| 决策 | 理由 |
|------|------|
| 告警由 AppDelegate 拉、托盘模型只接收 | 面板关闭时也要有徽标；托盘自己的 5 秒循环不再多打一个请求 |
| 告警请求串行在状态请求之后 | 告警要走状态里的连接配置，不能猜 |
| 徽标用文字数字而不是红色圆点 | 图标是模板图，混色会与深浅色外观打架；数字跟随菜单栏前景色 |
| 告警标题本地化、message 保留后端原文 | 后端文案目前是中文；标题本地化保证英文界面可读，明细放 tooltip |
| 告警点击跳到对应页面 | 事件与告警 issue 的验收项要求“点击进入对应页面” |
| 告警卡无告警时不占高度 | 面板高度有限，常态信息优先 |
