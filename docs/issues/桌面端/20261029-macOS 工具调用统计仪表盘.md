# Issue: macOS 工具调用次数统计仪表盘

## Goal

在 macOS 控制面板新增 Analytics 页面：按工具统计调用次数、错误、错误率与延迟分位，支持搜索与排序，并实时刷新。

## 背景/问题

`/internal/runtime/analytics` 已返回 `tool_stats`（count / error_count / error_rate / p50 / p95 / p99），但控制面板只在 Activity 页面展示最近调用，没有任何聚合视图。工具调用次数分布只能靠 curl 或日志人工统计。

## 验收标准 (Acceptance Criteria)

- [x] WHEN Core 健康，页面 SHALL 展示窗口调用、累计调用、错误数、错误率、进行中调用五个指标
- [x] WHEN 存在 tool_stats，系统 SHALL 以横向条形图展示各工具调用次数（按最大值为基准缩放）
- [x] WHEN 输入关键字，图表与明细表 SHALL 同步过滤
- [x] WHEN 切换排序，系统 SHALL 按调用次数 / 错误率 / P95 延迟重排
- [x] WHEN 工具数超过 24，图表 SHALL 显示前 24 个并注明总数
- [x] IF Core 未运行，THEN 页面显示不可用说明，不影响其他页面
- [x] WHERE Windows / Linux 桌面端，系统 SHALL 无行为变化

## 关键决策

| 决策 | 理由 |
|------|------|
| 新增独立 Analytics 页面 | Activity 的语义是"最近调用流水"，聚合统计放同一页会让两种时间尺度混在一起 |
| 自绘条形图而非 Charts 框架 | 只有横向单系列柱状图，自绘可控且不引入额外框架依赖 |
| 图表最多 24 条 | 32 个工具全画会失去比较意义；明细表保留全量 |
| 复用现有 analytics 端点 | 数据已存在，避免第二套统计口径 |
