# Issue: macOS 已发布文件链接展示（file_publish）

## Goal

在 macOS 控制面板新增 Published 页面：列出 `file_publish` 当前仍有效的发布记录，并显示可直接打开/复制的公网链接。链接必须与 `/artifacts/public/` 实际可下载地址一致。

## 背景/问题

`file_publish` 返回的 URL 只在当次工具结果里出现，模型会话结束后用户无法在桌面上找回；`public-artifacts/<id>/metadata.json` 里有完整元数据，但没有只读列表接口。

## 验收标准 (Acceptance Criteria)

- [x] WHEN 存在未过期发布记录，页面 SHALL 按创建时间倒序列出文件名、大小、类型、发布时间、过期时间
- [x] WHEN 配置了公网地址，每行 SHALL 显示签名链接，并提供打开与复制
- [x] WHEN 未配置公网地址，页面 SHALL 明确提示，但仍列出已发布文件
- [x] WHEN 记录已过期，SHALL 不显示（由 Cleanup 删除，避免死链）
- [x] IF Core 未运行，THEN 显示不可用说明
- [x] WHERE Windows / Linux 桌面端，系统 SHALL 无行为变化

## 关键决策

| 决策 | 理由 |
|------|------|
| 直接读 `metadata.json`，不新建发布索引 | 发布目录本身就是 SSOT；重建索引会产生不一致 |
| Publish/List 共用 `publicURL` | 链接含 expires+sig，两处各写一份必然漂移 |
| 过期记录不列出 | 链接已失效，显示只会误导 |
| 无公网地址时仍列出文件 | 用户至少要能看到发布过什么；链接等配置后再出现 |
